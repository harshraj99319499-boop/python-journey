# Chapter 1: Introduction to Python

## 1.1 Why Programming Language?
- Computers only understand binary (`0`s and `1`s).
- Programming languages allow humans to write readable instructions that computers translate into executable code.

## 1.2 Why Python?
- It is developed by Guido van Rossum.
- Python is easy to use and powerful.
- Python is easily understandable for both experts as well as beginners.
- Python is user friendly.
- It supports both object-oriented programming and structured programming.
- It is open source and platform independent.
- Python is highly recommended when learning to code.
- Python is an interpreted language.

## 1.3 Features of Python

- Object-Oriented Language: Python supports object-oriented concepts of classes, objects, encapsulation, and inheritance.
- Easy to Code: It is very easy to learn, as compared to other languages like C, C++, Java, etc[cite: 4]. It is also a developer friendly language.
- Free and Open Source: Python is freely available in internet[cite: 4]. Anyone can download python from ( www.python.org ).
- High-Level Language: Python is a high-level language[cite: 4]. It is simple and similar to English and can be easily understood.
- Interpreted Language: Python program is executed one line at a time[cite: 4]. It makes debugging easy and portable.
- Cross-Platform Language: Python can equally run on different platforms such as Windows, Linux, UNIX, . So python is portable language.
- Dynamic Memory Allocation: There is no need to specify the data-type of the variable. Python automatically allocates memory to variable at run time of the program. Ex: x=15 not int x=15.
- Embeddable: In python source code we can use other programming languages codes as well as, we can use python source code in other languages.
- GUI Programming: Python offers various libraries for making Graphical user interface for your applications.
