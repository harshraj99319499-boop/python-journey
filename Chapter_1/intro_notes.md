# Chapter 1: Introduction to Python

## 1.1 Why Programming Language?
- Computers only understand binary (`0`s and `1`s).
- Programming languages allow humans to write readable instructions that computers translate into executable code.

## 1.2 Why Python?
- Clean, simple, and readable syntax.
- Widely used in Cybersecurity, Automation, Web Development, and AI.
- Large ecosystem of built-in and external libraries.

## 1.3 Key Features of Python
- **Beginner-Friendly:** Easy to read and write.
- **Interpreted:** Executes code line-by-line.
- **Cross-Platform:** Runs on Windows, Linux, and macOS without changes.
- **Free and Open-Source:** Freely available for everyone.

## 1.4 & 1.5 Installation and Path Setup
- Installed Python from the official portal (`python.org`).
- Enabled **"Add python.exe to PATH"** to access Python globally via terminal/command line.
