# Chapter 3: Built-in Functions in Python

## 3.1 What are Built-in Functions?
- Pre-defined functions built directly into the Python interpreter.
- Always available for immediate use without importing external modules.

## 3.2 Common Built-in Functions
- **I/O Functions:** `print()`, `input()`
- **Type Conversion:** `int()`, `float()`, `str()`, `bool()`
- **Mathematical:** `abs()`, `round()`, `min()`, `max()`, `sum()`, `pow()`
- **Inspection & Utility:** `type()`, `len()`, `id()`
